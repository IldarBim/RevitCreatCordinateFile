# Изменения

## 0.2.10

- Отдельные колонки «Доп. префикс» и «Доп. кол-во» для второй группы моделей; прежняя группа BS сохраняется.
- Одна дополнительная модель именуется `PP`, несколько — `PP1`, `PP2`; `0` отключает дополнительную группу.
- Обе группы включены в предпросмотр, общее количество, создание и взаимное связывание.
- Добавлены проверки дополнительного количества, префикса и совпадающих имён; старые настройки открываются с отключённой дополнительной группой.
- В публикации GitHub восстановлены русские имена Excel-файлов рабочих наборов, искажённые в исходном ZIP. Содержимое Excel и собранная DLL не изменялись.

Проверка: 50 сценариев с собранной DLL и Revit API 2022; без создания/изменения настоящих RVT.

## 0.2.9

- Разрешён дефис в шифре проекта с сохранением шифра в настройках и именах RVT.
