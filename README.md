# TATBIM Project Creator

Плагин для **Autodesk Revit 2022**, версия **0.2.10**. Создаёт центральные RVT из шаблонов RTE, добавляет рабочие наборы из Excel и связывает модели по общим координатам через SF.

## Скачать 0.2.10

- [Полный комплект для установки](dist/0.2.10/TATBIM_Project_Creator_v0_2_10_Source.zip): исходники, установщик, настройки, Excel-файлы и собранная DLL.
- [Обновление установленного плагина](dist/0.2.10/TATBIM_Project_Creator_v0_2_10_Update.zip): DLL и Update.bat; настройки сохраняются.
- [Контрольные суммы SHA-256](dist/0.2.10/SHA256SUMS.txt).

Откройте нужный ZIP на GitHub и нажмите **Download raw file**. Архив нужно распаковать целиком.

## Чистая установка

Требуются Revit 2022, .NET SDK и компоненты для сборки .NET Framework 4.8. По умолчанию установщик использует Revit из `C:\Program Files\Autodesk\Revit 2022`.

1. Закройте Revit.
2. Распакуйте полный комплект и запустите `install.bat`. Он выполняет сборку и устанавливает файлы текущему пользователю.
3. Откройте Revit 2022. В окне плагина должна быть версия **0.2.10**.

Папка установки: `%APPDATA%\Autodesk\Revit\Addins\2022\TATBIM.ProjectCreator`. Файл `.addin` устанавливается рядом с этой папкой. Существующий `settings.json` не перезаписывается.

Для обновления закройте Revit, распакуйте архив обновления и запустите `Update.bat`. Он сохраняет резервную копию DLL и заменяет её, сохраняя настройки и рабочие наборы.

## Имена моделей и дополнительные копии

Формат имени: `<Шифр>-<Имя>-<Код раздела>-<Суффикс>-R22.rvt`. В шифре проекта разрешён дефис, например `123-45`.

Основная колонка **«Кол-во»** работает как прежде: `0` — не создавать основную группу; `1` — общая часть, например `ALL`; `2` и больше — `BS1`, `BS2` и далее.

Две независимые колонки **«Доп. префикс»** и **«Доп. кол-во»** добавляют вторую группу к основной. Префикс задаётся для каждого раздела отдельно.

| Основное кол-во | Доп. префикс | Доп. кол-во | Суффиксы файлов |
|---:|---|---:|---|
| 3 | PP | 0 | BS1, BS2, BS3 |
| 3 | PP | 1 | BS1, BS2, BS3, PP |
| 3 | PP | 2 | BS1, BS2, BS3, PP1, PP2 |
| 1 | PP | 1 | ALL, PP |
| 0 | PP | 1 | PP |

Например, `123-45-YYY-AR-PP-R22.rvt`. Одиночная дополнительная модель не получает индекс. Количество в каждой группе — целое число от 0 до 99; совпадающие имена отклоняются. SF остаётся единой моделью координации без дополнительных копий.

Обе группы входят в общий счётчик, предпросмотр, создание и взаимное связывание RVT. Они используют RTE, Excel и рабочие наборы соответствующего раздела. Для сохранения введённых значений нажмите **«Сохранить настройки»**.

## Порядок работы

1. Задайте шифр, имя и существующую корневую папку проекта. Папки разделов должны быть созданы заранее.
2. Укажите RTE для выбранных разделов и папку Excel с рабочими наборами.
3. Проверьте имена через «Предпросмотр», затем создайте SF.
4. Проверьте координаты SF, включите подтверждение и создайте остальные модели. Связывание выполняется после создания; для повторного запуска доступна кнопка «Связать RVT».

Готовые RVT не перезаписываются. При связывании отсутствующие модели пропускаются с записью в журнал. Используются существующие рабочие наборы из настроенного соответствия; дополнительные индексы в их имена не добавляются.

Для GS Excel в исходных настройках не задан: перед созданием этого раздела укажите свой файл рабочих наборов либо отключите раздел.

## Сборка и проверка

```powershell
dotnet build .\TATBIM.ProjectCreator.csproj -c Release -p:RevitPath="C:\Program Files\Autodesk\Revit 2022"
```

Целевая платформа — .NET Framework 4.8, библиотеки Revit API 2022. Пройдено 50 проверок с реальной собранной DLL: старые настройки, новые колонки, имена обеих групп, сохранение/загрузка, общий список создания/связей, допустимые количества и совпадения. Создание и связывание настоящих RVT в запущенном Revit в эту проверку не входили.

В публикуемом комплекте восстановлены русские имена 12 Excel-файлов из исходного архива; их содержимое и DLL сохранены без изменений. Все непустые ссылки Excel в исходных настройках разрешаются в существующие файлы.
